# Visual Ideas

For each headline, write to `issues/<month>/visuals.md`:
- **Shot:** the image in one sentence. Deadpan news photo beats cartoon; it should look like it could be real.
- **Caption:** a straight-faced photo caption that adds a second joke.
- **Image prompt:** a ready-to-paste prompt for an image generator (photorealistic, overcast Chicago light, local details).
- **Or shoot it yourself:** a version Casey could photograph in the neighborhood.

No real, identifiable people or faces. No real business signage presented in a negative light.
